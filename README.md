# PhoenixGe OS updates

apt repository for **PhoenixGe OS** (Debian 13 + KDE Plasma 6). Built and signed automatically by GitHub Actions.

Already on PhoenixGe? Updates arrive in Discover, or run `phoenixge-update`.

Older PhoenixGe install without this repo:

```sh
curl -fsSL https://shakogogokhia.github.io/phoenixge-updates/install.sh | sudo sh
```
